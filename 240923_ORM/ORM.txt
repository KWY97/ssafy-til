<ORM - Object-Relational-Mapping>
 - 객체 지향 프로그래밍 언어를 사용하여 호환되지 않는 유형의 시스템 간의 데이터를 변환하는 기술

 - 역할
  Django와 DB간에 사용하는 언어가 다르기 때문에 소통이 불가능함.
  Django에 내장된 ORM이 중간에서 이를 해석해줌으로서 소통이 가능해진다.
  우리가 집중해야 하는 부분은 1. django에서 ORM으로, 2. ORM에서 django로 어떻게 보낼지 집중해야 함.
  (DB에서 ORM으로 보내는건 신경쓰지 않아도 된다.)

<QuerySet API>
 - ORM에서 데이터를 검색, 필터링, 정렬 및 그룹화 하는 데 사용하는 도구
   (API를 사용하여 SQL이 아닌 Python 코드로 데이터를 처리)
   django에서 ORM으로 보낼 때 사용
   (ORM에서 django로 보낼 땐 'QuerySet' or 'Instance'로 보냄)

 - 기본적인 구문
  Article.objects.all()
  (Model class.Manager.Queryset API 형태)

 *) Query
  - 데이터베이스에 특정한 데이터를 보여 달라는 요청
  - "쿼리문을 작성한다" == "원하는 데이터를 얻기 위해 데이터베이스에 요청을 보낼 코드를 작성한다."
  - Python으로 작성한 코드가 ORM에 의해 SQL로 변환되에 DB에 전달되며, 
    DB의 응답 데이터를 ORM이 QuerySet이라는 자료 형태로 변환하여 우리에게 전달

  *) QuerySet
   - DB에게서 전달 받은 객체 목록 (데이터 모음)
     (데이터의 모음이기 때문에 순회가 가능하며, 1개 이상의 데이터를 불러와 사용할 수 있음)
   - Django ORM을 통해 만들어진 자료형
   - 단, DB가 단일한 객체를 반환할 때는 QuerySet이 아닌 모델(Class)의 'Instance'로 반환됨

 - 결론적으로 QuerySet API는 python의 모델 클래스와 인스턴스를 활용해 DB에 데어티럴 저장, 조회, 수정, 삭제하는 것 (CRUD)


<CRUD>
 - 소프트웨어가 가지는 기본적인 데이터 처리 기능
  1. Create(저장), 2. Read(조회), 3. Update(갱신), 4. Delete(삭제)
