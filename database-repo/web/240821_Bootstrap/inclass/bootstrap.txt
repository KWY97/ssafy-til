<Bootstrap>
 - CSS 프론트엔드 프레임워크 (Toolkit)
 - 미리 만들어진 다양한 디자인 요소들을 제공하여 웹 사이트를 빠르고 쉽게 개발할 수 있도록 함
 - 특정한 규칙이 있는 클래스 이름으로 스타일 및 레이아웃이 미리 작성되어 있음
 - 만들어 놓은 기능을 클래스로 제공 (so, 우리는 클래스 선택자 써서 사용해야함)


<CDN, Content Delivery Network>
 - 지리적 제약 없이 빠르고 안전하게 콘텐츠를 전송할 수 있는 전송 기술
 - 서버와 사용자 사이의 물리적인 거리를 줄여 콘텐츠 로딩에 소요되는 시간을 최소화 (웹 페이지 로드 속도를 높임)
 - 지리적으로 사용자와 가까운 CDN 서버에 콘텐츠를 저장해서 사용자에게 전달
 

<Bootsrtap 사용 가이드>
 - {property}{sides}-{size} (ex) mt-5 (margin, top, 5 라는 뜻 - px아님. rem 기준으로 만든 사이즈))

 *) rem: root em
 root: 브라우저의 기본 폰트 사이즈 - 16px

 Bootsrtap size (많이 쓸 것 같은 사이즈를 0~5 까지로 선언해놓은 것. 없는 것은 우리가 직접 사이즈 선언하면 댐)
 0 = 0 rem = 16px * 0 = 0px
 1 = 0.25rem = 16px * 0.25 = 4px
 2 = 0.5 rem = 16px * 0.5 = 8px
 3 = 1 rem
 4 = 1.5 rem
 5 = 3rem
 

<Reset CSS>
 - 모든 HTML 요소 스타일을 일관된 기준으로 재설정하는 간결하고 압축된 규칙 세트
 - HTML Element, Table, List 등의 요소들에 일관성 있게 스타일을 적용시키는 기본 단계

 - 쉽게 말해 브라우저(크롬, 파이어폭스, 엣지 등)에 따라 요소마다 가지고 있는 고유한 스타일(user agent style sheet)이 있음
   개발자는 크롬 브라우저를 기준으로 만들었는데 사용자는 다른 브라우저를 쓰면 개발한 것과 다르게 보일 수 있기에
   개발한 웹을 모든 브라우저에서 똑같이 볼 수 있게 reset 해주는 것

 - Normalize CSS
   - Reset CSS 방법 중 대표적인 방법
   - 웹 표준을 기준으로 브라우저 중 하나가 불일치 한다면 차이가 있는 브라우저는 수정하는 방법


<Bootsrtap 활용> - 꼭 공식문서 켜놓고 활용
 - Typography: 제목 본문 텍스트 목록 등 (01 자료 참고)
 - Colors: Bootsrtap이 지정하고 제공하는 색상 시스템 (02 자료 참고)
 - Component: Bootsrtap에서 제공하는 UI 관련 요소 (04자료 참고)
   - 장점: 일관된 디자인을 제공하여 웹 사이트의 구성 요소를 구축하는데 유용하게 활용
   - Alerts
   - Badges
   - Buttons
   - Card (아주 많이 쓴다고 잘 알아놓으라고함)
   - Navbar
   

   <carousel이나 modal 같이 사용자와 상호작용하는 컴포넌트의 경우 2개 이상을 쓸 떄 data-bs-target과 id를 잘 봐야한다.>
   - carousel (05 자료 참고)
     - 주의: id 속성 값과 각 버튼의 data-bs-target 속성 값이 각각 올바르게 일치하는지 확인

   - modal (06 자료 참고)
     - 주의: modal id 속성 값과 각 버튼의 data-bs-target 속성 값이 각각 올바르게 일치하는지 확인
     - modal button과 modal 본체가 함께 다닐 필요 없다.
     - modal 본체는 버튼을 눌러야만 활성화되는 코드이기 때문에 코드 최하단에 모아두는 것이 편하다.

<Bootsrtap 사용하는 이유>
 1. 가장 많이 사용되는 CSS 프레임워크
 2. 사전에 디자인된 다양한 컴포넌트 및 기능 (빠른 개발과 유지보수)
 3. 손쉬운 반응형 웹 디자인 구현
 4. 커스터마이징 용이
 5. 크로스 브라우징 지원 (모든 주요 브라우저에서 작동하도록 설계되어 있음)
