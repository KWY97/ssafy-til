<CSS Flexbox> !!중요한 부분!! - justify - 주축!!,  align - 교차축!!
요소를 행과 열 형태로 배치하는 1차원 레이아웃 방식 (공간 배열 & 정렬)
flex container를 만들고 그 안에 아이템 요소들이 있는 것

 - flexbox 구성요소
   1. flex container (부모)
     display: flex; 를 부모에게 주면 컨테이너의 1차 자식 요소들이 flex item이 된다.
     flex box 속성 값들을 사용하여 자식 요소 flex item들을 배치하는 주체
     flex item에게 배치를 시키기보다 가장 가까운 부모에게서 접근을 하는 방식이 좋다. 

   2. flex item (자식 요소)

   3. main axis(주 축)
     flex item들이 배치되는 기본 축
     main start에서 시작하여 main end 방향으로 배치 (기본: 왼쪽 -> 오른쪽으로)

   4. cross axis(교차 축) (main 축을 기준으로 수직 방향으로 결정됨)
     main axis에 수직인 축
     cross start에서 시작하여 cross end 방향으로 배치 (기본: 위 -> 아래)

<flexbox 속성 목록>
- flex container 관련 속성
1. flex-direction
    flex-direction: column; 하면 main 축의 시작이 위->아래 된다 (row가 기본 값)
    flex-direction: column-reverse; 하면 main 축의 시작이 아래->위
    flex-direction: row-reverse; 하면 main 축의 시작이 오른쪽 ->왼쪽

2. flex-wrap
    flex-wrap: wrap; 하면 flex container 행 안에 flex item 안들어가면 다른 행에 배치할지 여부 설정 (nowrap이 기본 값)

3. justify-content
    주 축을 따라 flex item과 주위에 공간을 분배
    center, flex-start(기본값), flex-end

4. align-content
    교차 축을 따라 flex item과 주위에 공간을 분배
    flex-wrap이 wrap또는 wrap-reverse로 설정된 여러 행에만 적용됨
    한 줄 짜리 행에는 효과 없음 (flex-wrap이 nowrap인 경우)

5. align-items
    교차 축을 따라 flex item 행을 정렬
등

- flex item 관련 속성
1. align-self
    교차 축을 따라 개별 flex item을 정렬

2. flex-grow
    남는 행 여백을 비율에 따라 각 flex item에 분배
    아이템이 컨테이너 내에서 확장하는 비율을 지정
    반대는 flex-shrink
    
3. flex-basis
    flex item의 초기 크기 값을 지정
    flex-basis와 width 값을 동시에 적용한 경우 flex-basis가 우선

4. order
등
