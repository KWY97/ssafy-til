<Bootstrap Grid System>
 - 웹 페이지의 레이아웃을 조정하는데 사용되는 12개의 컬럼으로 구성된 시스템
 (12개인 이유: 1. 약수가 많음, 2. 적당히 큰 수)

 - 목적: 반응형 디자인을 지원해 웹 페이지를 모바일, 태블릿, 데스크탑 등 다양한 기기에서 적절하게 표시할 수 있도록 도움

 - 반응형 웹 디자인: 디바이스 종류나 화면 크기에 상관없이 어디서든 일관된 레이아웃 및 사용자 경험을 제공하는 디자인 기술


<Grid System의 구조>
 - 기본 요소
  1. container: column들을 담고 있는 공간
  2. column: 실제 컨텐츠를 포함하는 부분 (하나의 컨테이너에 12개의 column 들어감)
  3. gutter: 컬럼과 컬럼 사이의 여백 영역
  4. row: container안에 row가 있고 column들은 row안에서 12개로 존재 (교재엔 없는 부분)
  *) column이 12개가 넘어가면 그 전까지만 하나의 row에 담기고 나머지는 다음 row로 넘어감
  *) 구조 파악할 때 작은 것은 코드에서 접어놓고 큰 틀부터 하나씩 만들고 확인하면서 코드 작성하기

  tip 1) 같은줄에서 동시에 작성하고 싶은땐 ctrl + alt 하고 아래로 커서를 이동시키면 동시작성 가능
  tip 2) 라인 선택하고 싶을 때 라인에 커서 올리고 ctrl + L 하면 동시선택 (여러 줄 도 가능)
  tip 3) 옮길 줄 드래그 하고 alt 누르고 방향키 옮기면 그대로 옮겨진다. (alt + shift 하고 하면 복사됨)


  <Responsive Web Design>
 - 디바이스 종류나 화면 크기에 상관없이 어디서든 일관된 레이아웃 및 사용자 경험을 제공하는 디자인 기술
 - Bootstrap grid system에서는 12개의 column과 6개의 breakpoints를 사용하여 반응형 웹 디자인을 구현

 - Grid system breakpoints: 웹 페이지를 다양한 화면 크기에 적절하게 배치하기 위한 분기점
   화면 너비에 따라 6개의 분기점 제공 (xs, sm, md, lg, xl, xxl)
   각 breakpoints 마다 설정된 최대 너비 값 "이상으로" 화면이 커지면 grid system 동작이 변경됨
   *주의 사항) xs만 미만이고, 다른 것은 모두 이상임. 또한 xs 키워드는 작성하지 않음 (교재 33p)
