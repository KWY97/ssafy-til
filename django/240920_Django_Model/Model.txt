<Django Model>
 - DB의 테이블을 정의하고 데이터를 조작할 수 있는 기능들을 제공
   테이블 구조를 설계하는 청사진(blue print)
   (DB와의 소통, 조작, 설계 등을 담당 한다고 보면됨)

 - 작성한 모델 클래스는 최종적으로 DB에 아래와 같은 테이블 구조를 만듬
   (DB안에 여러개의 테이블이 있는 것 !! 하나만 있는 것이 아님)
   (DB가 테이블보다 큰 개념)

    id     title    content
    ..       ..        ..
    ..       ..        ..

  - id 필드는 Django가 자동생성 해줌
  - 클래스 변수명: 테이블의 각 필드(열) 이름 (위 테이블에서는 title, content)

  - 이 부분은 교재 보며 보기 (9p)
  django.db.models 모듈의 Model이라는 부모 클래스를 상속받음
  Model은 model에 관련된 모든 코드가 이미 작성되어 있는 클래스 (약 2000줄 짜리 코드)
  !!! 개발자는 가장 중요한 테이블 구조를 어떻게 설계할지에 대한 코드만 작성하도록 하기 위한 것 (상속을 활용한 프레임워크의 기능 제공) !!!

  Model Field
   - 데이터베이스 테이블의 열(column)을 나타내는 중요한 구성 요소
   - '데이터의 유형(str, int 등)'과 '제약조건'을 정의

<Model Field>
 DB 테이블의 필드(열)를 정의하며, 해당 필드에 저장되는 데이터 타입과 제약조건을 정의

 !!! Model Field 구성 !!!
 1. Field types (필드 유형)
  - 데이터베이스에 저장될 '데이터의 종류'를 정의 (models 모듈의 클래스로 정의되어 있음)
  - 주요 필드 우형
    - 문자열 필드: CharField, TextField
      - CharField()
      제한된 길이의 문자열을 저장 (필드의 최대 길이를 결정하는 !! max_length는 필수 옵션 !!)

      - TextField()
      길이 제한이 없는 대용량 텍스트를 저장 (무한대는 아니며 사용하는 시스템에 따라 달라짐)

    - 숫자 필드: IntegerField, FloatField
    - 날짜/시간 필드: DateField, TimeField, DataTimeField
    - 파일 관련 필드: FileField, ImageField

    -> 필드 유형이 아주 많으니 필요한 것이 있으면 공식문서 들어가서 더 찾아보면 된다.
    (* 공식문서 찾아볼 때 장고 버전 잘 맞춰서 보기. 우리는 4.2 사용한다.)


 2. Field options
  - 필드의 '동작'과 '제약조건'을 정의
  - 주요 필드 옵션
    - null
      - 데이터베이스에서 'NULL 값'을 허용할지 여부를 결정 (기본값: False)

    - blank
      - form에서 '빈 값'을 허용할지 여부를 결정 (기본값: False)

    - default
      - 필드의 기본값을 설정

  -> 필드 유형만큼은 아니지만 필드 옵션도 많으니 필요한 것이 있으면 공식문서 들어가서 더 찾아보면 된다.

  - 제약 조건(Constraint)
   특정 규칙을 강제하기 위해 테이블의 열이나 행에 적용되는 규칙이나 제한사항
   ex) 숫자만 저장되도록, 문자가 100자 까지만 저장되도록 하기 등
