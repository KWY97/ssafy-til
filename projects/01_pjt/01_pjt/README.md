# 240718 - 관통PJT
## 주제: 버전 2 - 영화 추천 서비스
- 학습 목표: 파이썬으로 도서 및 아티스트 데이터 가공 및 미션 수행 (도서 선택)
    - 필수 요구사항
        - A. 제공되는 도서 데이터의 주요내용 수집
        - B. 제공되는 도서 데이터의 주요내용 수정
        - C. 다중 데이터 분석 및 수정
        - D. 가장 리뷰가 높은 도서 데이터 수집
        - E. 특정 년도에 출판한 도서 데이터 수집 

        -> A, B, C 완료, D 진행중
---

- 어려웠던내용
    requests를 사용해서 정보를 얻어 온다는 것 자체가 처음해보는 일이라 많이 어색했습니다. 눈으로 볼 땐 쉽고 이해되지만 역시나 혼자 할 때는 버벅거렸습니다. 또한 .json 파일에서 필요한 정보를 가져올 때, 문제가 어려워질수록 요구하는 데이터 또한 많아져 많이 복잡했습니다.
---

- 새로배운내용 및 느낀점
    전체적으로 문법도 다시 익혀야 할 것 같고, 데이터 구조에 대한 이해가 필요한 것 같습니다. 또한 반복문과 조건문을 상황에 맞게 적절히 사용할 수 있어야 한다고 생각하며, 유연한 사고가 필요할 것 같습니다. 또한 함수 부분이 가장 어색했는데, 함수 공부에 시간을 많이 투자해야 할 것 같습니다.
