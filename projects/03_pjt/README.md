# 240823 - 관통PJT
## 주제: 반응형 웹 포트폴리오 사이트 만들기
- 학습 목표: 본인만의 반응형 웹 포트폴리오 사이트 만들기
    - 요구사항
        1. UI 설계부터 구현까지 스스로 하기
        2. Bootstrap & CSS 적절히 사용
        3. 다양한 화면 크기에서 서비스 가능한 반응형 웹 구현

- 어려웠던내용
  - 반응형 디자인 구현: 다양한 화면 크기에서도 사이트가 잘 보이게 하기 위해 반응형 웹을 만들었는데, 
    그것을 구현 하는게 가장 어려웠습니다. 스크린의 사이즈를 고려해서 레이아웃 조정과 요소의 크기 및 배치를 어떻게 해야 할지 고민을 많이 했습니다. 또한 Bootstrap의 그리드 시스템을 활용했는데, 인공지능의 도움을 많이 받았습니다. 그렇기 때문에 더 공부를 해야할 것 같고 조정이 CSS 미디어 쿼리가 특히 좀 많이 낯설어 사용하는 것이 어려웠습니다.

  - UI 구현: 수업을 들을 때는 정말 이해하기도 쉬웠고, 해볼만 하다고 생각했습니다. 그런데 사이트를
    괜찮게 설계하는 것부터 정말 많이 어려웠으며, 실제로 완성된 페이지를 봐도 완성도가 많이 낮다고 생각합니다. 이를 통해 제가 일반적으로 접하던 사이트들이 얼마나 대단한 것인지 알게 되었습니다.


- 새로배운 내용 및 느낀점
  - UI/UX 디자인의 중요성: 구현에 앞서 대충 설계를 해봤는데 참고자료가 없었다면 전혀 설계를 못했을 
    것 같을 정도로 생각보다 UI가 어려웠습니다. UI 설계에서 각 요소들의 크기나 위치 등을 결정하는 것이 어렵고 중요한지 알게 됐습니다. 또한 수업 때 예시 자료로 공원을 예쁘게 설계 했는데 사람들이 길로 다니지 않고 공원 잔디를 가로질러 가는 그림을 본 적이 있습니다. 그 때 UX 고려도 정말 중요하다고 생각 했으며, 제가 구현한 포트폴리오에서는 사용자 경험(UX)을 고려해 큰 카테고리부터 세부사항이 순서대로 이어지게 제작했습니다.

  - Bootstrap 활용의 유용성: bootstrap을 활용하면 많은 css 작업을 줄일 수 있고, 빠르게 
    프로토타입을 만들 수 있다는 것을 느꼈습니다. 하지만, bootstrap은 구현할 수 있는 것에 대해 제약이 많았으며 기존 css보다 문법이 직관적이지 않아 생각하기가 어려워 항상 공식문서를 보면서 진행 했습니다. 아직까지 저는 css가 편하지만 bootstrap도 연습을해서 잘 활용하고 싶습니다.
